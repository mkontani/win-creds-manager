# wcm v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Windows Hello（TPM バック）で保護された単一ファイルのクレデンシャルボルトを操作する Rust CLI `wcm` を、macOS 上で開発・テストし、Windows 向けにクロスビルドできる状態で完成させる。

**Architecture:** `wcm-core`（可搬・unsafe 禁止：形式/暗号/スロット/アイテム）→ `wcm-hello`（Windows のみ：KeyCredentialManager バックエンド、DPAPI、focus、session）→ `wcm-cli`（clap、コマンド、出力、WSL シム、ssh/clip ヘルパ）。バックエンドは ikm を返すだけで、HKDF/AEAD ラップは core が担う。

**Tech Stack:** Rust 1.89 (edition 2021), clap 4, serde+ciborium(CBOR)+serde_json, chacha20poly1305 0.10 (XChaCha20-Poly1305), hkdf 0.12, sha2 0.10, argon2 0.5, rsa 0.9, rand 0.8, zeroize, secrecy, tempfile, fd-lock, directories, rpassword, arboard, ssh-key, windows 0.62.2, assert_cmd/predicates, cargo-llvm-cov.

**Spec:** `docs/superpowers/specs/2026-08-19-wcm-design.md`

## Global Constraints

- edition 2021, MSRV 1.85（開発ツールチェーン 1.89）。`wcm-core` は `#![forbid(unsafe_code)]`。
- RustCrypto は digest-0.10 系（sha2 0.10.x / hkdf 0.12.x / chacha20poly1305 0.10.x / argon2 0.5.x / rsa 0.9.x / rand 0.8.x）。混在禁止。
- `windows = "=0.62.2"`（`IAsyncOperation::join()`）。`wcm-hello` の実体は `cfg(windows)` のみ。
- 終了コードは ≤125（WSL `/init` の 8bit 打ち切り対策）。JSON エラーは stderr、exit code は常に真。
- 秘密は `Zeroizing`/`SecretString` で保持、ログに出さない。バイナリを TTY に書かない。
- コミットは Conventional Commits（`feat:`, `test:`, `docs:` …）。各タスク末で `cargo fmt && cargo clippy --all-targets -- -D warnings && cargo test` を通す。
- カバレッジ目標 80%（`cargo llvm-cov --workspace --exclude wcm-hello`）。

// wcm-core/src/error.rs
#[derive(Debug, thiserror::Error)]
pub enum Error {
    #[error("item not found: {0}")] NotFound(String),                     // exit 3
    #[error("item already exists: {0}")] AlreadyExists(String),           // exit 4
    #[error("vault not initialized at {0}")] NotInitialized(String),      // exit 5
    #[error("authentication cancelled")] AuthCancelled,                   // exit 6
    #[error("authentication unavailable: {0}")] AuthUnavailable(String),  // exit 7
    #[error("vault integrity error: {0}")] Integrity(String),             // exit 8 (AEAD/SPKI/format)
    #[error("vault locked or modified concurrently")] Locked,             // exit 9
    #[error("i/o error: {0}")] Io(String),                                // exit 10
    #[error("helper failed: {0}")] Helper(String),                        // exit 11
    #[error("import/export format error: {0}")] Format(String),           // exit 12
    #[error("invalid input: {0}")] Invalid(String),                       // exit 2
    #[error("{0}")] Other(String),                                        // exit 1
}
impl Error { pub fn exit_code(&self) -> u8; pub fn code(&self) -> &'static str /* "NOT_FOUND" 等 */; pub fn hint(&self) -> Option<String>; }
pub type Result<T> = std::result::Result<T, Error>;

pub fn random_nonce() -> [u8; 24]; pub fn random_key() -> Zeroizing<[u8; 32]>; pub fn random_bytes<const N: usize>() -> [u8; N];

// wcm-core/src/crypto/kdf.rs

impl Argon2Params { pub const DEFAULT: Self = Self { m_kib: 65536, t: 3, p: 1 }; pub const FAST_TEST: Self = Self { m_kib: 64, t: 1, p: 1 }; }

// wcm-core/src/slot/mod.rs
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)] #[repr(u8)] pub enum SlotKind { Hello = 1, Passphrase = 2 }
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)] #[serde(tag = "kind")]
pub enum SlotParams {
    Hello { cred_name: String, #[serde(with = "serde_bytes")] challenge: Vec<u8> /*32*/, #[serde(with = "serde_bytes")] spki_der: Vec<u8>, dpapi: bool, hw_backed: bool },
    Passphrase { argon2: Argon2Params },
}
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct KeySlot { pub id: u8, pub label: String, #[serde(with="serde_bytes")] pub salt: Vec<u8> /*32*/, #[serde(with="serde_bytes")] pub nonce: Vec<u8> /*24*/, #[serde(with="serde_bytes")] pub ct: Vec<u8>, pub params: SlotParams }
impl KeySlot { pub fn kind(&self) -> SlotKind; }
#[derive(Clone, Debug, PartialEq, Eq)] pub enum Availability { Available, NotEnrolled, Unsupported(String), NoInteractiveSession }
pub trait Prompter { fn secret(&self, label: &str) -> Result<SecretString>; fn confirm(&self, msg: &str) -> Result<bool>; fn notice(&self, msg: &str); }
pub struct UnlockContext<'a> { pub vault_id: [u8; 16], pub reason: &'a str, pub prompter: &'a dyn Prompter, pub allow_ui: bool }
pub trait KeySlotBackend {
    fn kind(&self) -> SlotKind;
    fn availability(&self) -> Availability;
    fn enroll(&self, ctx: &UnlockContext) -> Result<(SlotParams, Zeroizing<Vec<u8>>)>;
    fn open(&self, ctx: &UnlockContext, params: &SlotParams) -> Result<Zeroizing<Vec<u8>>>;
    fn destroy(&self, params: &SlotParams) -> Result<()>;
}
pub trait Envelope { fn protect(&self, vault_id: &[u8; 16], data: &[u8]) -> Result<Vec<u8>>; fn unprotect(&self, vault_id: &[u8; 16], data: &[u8]) -> Result<Vec<u8>>; }
pub struct IdentityEnvelope; // impl Envelope (identity)
pub type Dek = Zeroizing<[u8; 32]>;
pub fn seal_slot(id: u8, label: &str, backend: &dyn KeySlotBackend, envelope: &dyn Envelope, ctx: &UnlockContext, dek: &Dek) -> Result<KeySlot>;
pub fn open_slot(slot: &KeySlot, backend: &dyn KeySlotBackend, envelope: &dyn Envelope, ctx: &UnlockContext) -> Result<Dek>;
pub fn slot_aad(vault_id: &[u8; 16], id: u8, kind: SlotKind) -> Vec<u8>; // b"wcm/v1/slot" || vault_id || id || kind

// wcm-core/src/slot/passphrase.rs
pub struct PassphraseBackend { pub params: Argon2Params, pub secret: Option<SecretString> /* None → ctx.prompter.secret() */ }
// wcm-core/src/slot/mock.rs (feature test-util)

// wcm-core/src/item.rs
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize, clap::ValueEnum?)] // clap は cli 側で別 enum を用意する
#[serde(rename_all = "kebab-case")] pub enum ItemKind { Password, Login, Token, SshKey, File, Note }
impl ItemKind { pub fn primary_field(&self) -> &'static str /* password,password,token,private_key,content,note */; pub fn parse(s:&str)->Option<Self>; pub fn as_str(&self)->&'static str; }
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)] #[serde(untagged)] pub enum FieldValue { Text(String), Bytes(#[serde(with="serde_bytes")] Vec<u8>) }
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)] pub struct Field { pub value: FieldValue, pub secret: bool }
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct Item { #[serde(with="serde_bytes")] pub id: Vec<u8> /*16*/, pub name: String, pub kind: ItemKind, pub fields: BTreeMap<String, Field>, pub notes: String, pub tags: Vec<String>, pub created: String /*RFC3339*/, pub updated: String }
impl Item { pub fn new(name: &str, kind: ItemKind, now: &str) -> Item; pub fn with_field(self, k: &str, f: Field) -> Item; pub fn without_field(self, k:&str) -> Item; pub fn primary(&self) -> Option<&Field>; pub fn touched(self, now:&str)->Item; }
pub fn validate_name(name: &str) -> Result<()>;   // 1..=200 chars, no control chars, no leading '-', no '/' at ends, no ".."

// wcm-core/src/vault/header.rs

impl Header { pub fn encode(&self) -> Result<Vec<u8>> /* magic+len+cbor */; pub fn decode(bytes: &[u8]) -> Result<(Header, usize /*prefix len*/)>; pub fn vault_id_arr(&self) -> [u8;16]; }

// wcm-core/src/vault/body.rs

    pub fn rename(&self, old: &str, new: &str, now: &str) -> Result<VaultBody>;
    pub fn update<F: FnOnce(Item) -> Result<Item>>(&self, name: &str, f: F) -> Result<VaultBody>;
    pub fn list(&self, prefix: Option<&str>, kind: Option<ItemKind>, tag: Option<&str>) -> Vec<&Item>;  // sorted by name
    pub fn encode(&self) -> Result<Vec<u8>>; pub fn decode(b: &[u8]) -> Result<VaultBody>;
}

// wcm-core/src/vault/mod.rs
pub struct Vault { pub path: PathBuf }
pub struct UnlockedVault { pub header: Header, pub body: VaultBody, dek: Dek, loaded_generation: u64 }
impl Vault {
    pub fn new(path: impl Into<PathBuf>) -> Vault;

    pub fn read_header(&self) -> Result<Header>;                    // NotInitialized if missing
    pub fn create(&self, header_slots: Vec<KeySlot>, dek: Dek, vault_id: [u8;16], now: &str) -> Result<UnlockedVault>;   // fails if exists
    pub fn open_with_dek(&self, dek: Dek) -> Result<UnlockedVault>;   // Integrity on AEAD fail
    pub fn unlock(&self, choose: &dyn Fn(&KeySlot) -> Option<(&dyn KeySlotBackend, &dyn Envelope)>, ctx: &UnlockContext, preferred_label: Option<&str>) -> Result<UnlockedVault>; // tries slots in order (preferred first)
}
impl UnlockedVault {
    pub fn dek(&self) -> &Dek;
    pub fn save(&mut self, vault: &Vault) -> Result<()>;   // generation+1, fresh nonce, atomic write, .bak; Locked if on-disk generation != loaded_generation

    pub fn with_slots(self, slots: Vec<KeySlot>) -> UnlockedVault;
}
